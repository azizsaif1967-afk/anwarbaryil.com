How to import a newsletter from a PDF, CSV, HTML or TXT file (step by step)

Every file type: the same 6 steps

  1. Prepare your file on your computer (see the rules for each type below).
  2. Click the gold Import file (PDF / HTML / CSV) button and choose the file.
  3. Wait for the green line under the Send buttons: "Imported … Check the preview". Subject and Body are now filled in.
  4. Scroll to Preview and read it as a student would. Fix any word directly in the Body box; the preview updates as you type.
  5. Type your own email in the test box and click Send test. Open it on your phone and check it.
  6. Click Send to all subscribers. It asks once more ("Yes, send to …"): click again to send. The result appears in Sent log.

PDF

  1. Write the newsletter in Word, Google Docs or Canva and Save / Download as PDF.
  2. Put the subject as the very first line, e.g. "December seminars in Chennai".
  3. Use short lines with no full stop for headings. Normal sentences become paragraphs.
  4. Type web addresses in full (https://…); they become clickable links.
  5. Photos inside the PDF are not copied. After importing, click in the Body where the photo should go and use Insert image.
  6. A scanned or photographed page has no text to read. Use the TXT way instead.

CSV (Excel / Google Sheets)

  1. Click CSV template to download the example and open it in Excel or Google Sheets.
  2. Keep the first row (column names) exactly as it is.
  3. Row 2: fill subject and, if needed, from_name, from_email, reply_to.
  4. Each row is one section: heading, text, optional image_url (a web link to a photo), optional button_text + button_url.
  5. A WhatsApp link (https://wa.me/…) makes a green button; any other link makes a gold one.
  6. Save as CSV (File, Download, Comma-separated values) and import it.

HTML

  1. Use this when the newsletter is already designed (Mailchimp, Canva email, or a sample we sent you).
  2. Export or save it as an .html file.
  3. The design is kept as it is. Anwar's header is not added, so the file should carry its own.
  4. The page title becomes the Subject. If the file has no title, type the Subject yourself.
  5. Images must be web links (https://…), not files on your computer.

TXT (plain text, easiest)

  1. Open Notepad (Windows) or TextEdit (Mac, Format, Make Plain Text).
  2. Line 1 = subject. Leave one empty line between paragraphs.
  3. A short line with no full stop becomes a heading.
  4. Save as .txt and import. Anwar's header, greeting and WhatsApp button are added for you.

Good to know: {{name}} anywhere in the Body becomes each student's name. The unsubscribe line is added automatically. The file never leaves your computer; it is converted inside this page. Importing replaces the Body box, so import first and then edit.
